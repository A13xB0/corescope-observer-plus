    Guest key

    Off

    A guest identity used to poll a repeater, so any observer that hears the reply can feed CoreScope. This observer makes its own key and registers it with CoreScope, which decodes the replies others overhear and credits them here; on a CoreScope without that, the public shared key is used instead. CoreScope also picks one observer to poll each repeater, so others don't repeat the request. Opt a repeater in from its Details. The key only ever logs in blank or with "hello", never as admin.
