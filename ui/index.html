    Key

    This repeater has a saved password, so the guest key can't be used. Remove the password first.

    What does the guest key share?

    Polls under a separate polling key the plugin made, so other observers can feed CoreScope the readings. CoreScope gets that polling key to decrypt them; this repeater's own key is never shared.

    • Anyone can read its replies. That's the point: other observers feed CoreScope.
    • It is only ever used with a blank or hello password.
    • Never give this key admin on any repeater. If it ever answers as admin, the plugin stops, removes the key's access and tells you.

    Which password should I use?

    Blank logs in automatically: as a guest when the repeater has no guest password, or through its ACL if it lists this plugin's key. A password is kept on this observer only and never published. An admin password works but gives full control and makes the repeater write to flash at each login, so prefer a guest password or an ACL entry. Saving one stops the guest key here.

    Reading the log

    An answer is either heard on this node's radio or found in the packets CoreScope's observers heard. A flooded answer means the repeater had no route back to this station.

    Polling

    About four times the airtime of a battery reading. Never sent through a relay.
    A 1 hop request costs the relay two transmissions.
    Does the plugin flood?

    No. Every packet it sends goes direct. A repeater floods its answer only when it has no route back, so the plugin sends it one before asking.

    Publish to

    Brokers set up in openHop. Guest-key readings reach CoreScope through openHop's own uploads.

    Why is Last publish empty for guest-key readings?

    Readings under the companion key (repeaters with a saved password) go out under this repeater's key on their own short connection; openHop's connection is not touched. Guest-key readings aren't published here: openHop uploads the repeater's reply like any packet it hears, and CoreScope decrypts it with the polling key.
